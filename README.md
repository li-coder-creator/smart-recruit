## 📖 项目简介

**Smart Recruit** 是一个基于 **Spring Boot 3** 开发的前后端分离智能招聘系统。

项目面向**求职者**与**企业**两类用户，模拟真实招聘平台的核心业务场景，目前已实现：

- 用户注册与登录
- JWT 身份认证
- 企业与岗位管理
- 简历管理
- 岗位投递
- 企业处理投递

后端采用 **Spring Boot + MyBatis + MySQL** 技术栈，通过 RESTful API 为前端提供业务接口，并已完成核心业务模块的前后端接口联调。

前端项目采用 **Vue 3** 开发，独立维护于前端仓库。

```text

│         Vue 3 前端           │
```

```text

    ↓
Mapper
    ↓
MySQL
```

# 🌟 项目亮点

### 1. JWT 身份认证

使用 JWT 实现用户登录后的身份认证，并通过登录拦截器统一进行 Token 校验。

---

### 2. ThreadLocal 用户上下文

登录拦截器解析 Token 后，将当前用户信息保存至 ThreadLocal，业务层可直接获取当前登录用户。

请求完成后清理 ThreadLocal，避免线程复用导致的数据污染。

---

### 3. 核心业务权限校验

针对岗位、简历、企业等核心业务资源进行归属与权限校验，避免越权操作。

---

### 4. 完善的业务规则校验

投递模块实现：

- 岗位状态校验
- 简历归属校验
- 重复投递校验
- 企业权限校验

---

### 5. 统一异常处理

通过全局异常处理机制统一处理业务异常与参数校验异常，规范接口错误响应。

---

### 6. 前后端分离与接口联调

后端通过 RESTful API 提供业务服务，并与 Vue 3 前端完成核心业务模块的接口联调。

前端项目独立维护于前端仓库。
