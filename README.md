## 📖 项目介绍

Smart Recruit 是一个基于 **Spring Boot + Vue3** 的前后端分离智能招聘平台。

项目模拟真实互联网招聘业务，支持求职者和企业完成招聘流程。

本项目采用企业级开发方式，持续迭代开发，目标达到校招 Java 后端项目标准。

---
