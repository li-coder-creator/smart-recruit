# 普通岗位查询契约

日期：2026-11-01。目标：完成原型“全部岗位”的审核过滤、关键词搜索和薪资排序。

## 请求与权限

`GET /job`，当前登录求职者；响应仍为 `Result<PageResult<JobListVO>>`，列表位于 `data.items`，岗位总数位于 `data.total`。

| 参数 | 类型 | 默认值 | 规则 |
| --- | --- | --- | --- |
| page | Integer | 1 | 大于等于1 |
| size | Integer | 10 | 1～100 |
| keyword | String | 空 | 首尾trim后搜索；空字符串表示全部可见岗位 |
| sort | JobBrowseSort | UPDATED_DESC | UPDATED_DESC / SALARY_DESC，精确匹配枚举代码；省略或空字符串使用默认值 |

接口不接收企业审核状态和岗位状态参数。Service 固定传入 `CompanyStatus.APPROVED` 与 `JobStatus.ACTIVE`，客户端不能扩展可见范围。该阶段不修改普通岗位详情及投递接口的既有准入逻辑，也不修改企业管理的状态范围。

成功HTTP200/code200；非法业务参数、非法排序/数字格式HTTP200/code500且data=null；未登录HTTP401。错误信息放在 `message` 字段。

## 过滤与搜索

SQL 条件为：`岗位招聘中 AND 企业审核通过 AND (任一搜索字段命中)`。企业关联不存在时不会出现在普通列表。无论命中企业名、技能、标题中的哪一项，都必须满足前两个条件。

搜索字段：标题、类别、城市、部门、企业当前展示名称、必备能力和加分能力。

- LEGACY_TEXT：从 `job.required_skills` 模糊搜索。
- STRUCTURED：从 `job_required_ability.raw_text` 或 `ability_name` 模糊搜索。空子表不回退旧投影字符串。
- 加分能力：从 `job.preferred_skills` 模糊搜索。
- SQL 全部使用绑定参数。LIKE 沿用现有 `%关键词%` 语义；用户输入的 `%`、`_` 仍具有LIKE通配符含义，不代表绕过审核过滤。大小写遵从当前数据库排序规则。
- 搜索是文本检索，不复用推荐的技能名称/别名评分或语义模型。
- 用 EXISTS 判断能力命中，避免一岗多能力造成分页重复。

普通列表仍可展示已投递或截止日期已过的在招岗位。推荐接口的两个排除开关只属于推荐契约。

## 排序规则

| sort | 顺序 |
| --- | --- |
| UPDATED_DESC | 更新时间降序，再按岗位ID降序 |
| SALARY_DESC | 有效月薪上限降序；其余薪资记录置后；相同排序值按更新时间降序、岗位ID降序 |

“有效月薪”同时要求：salaryUnit=MONTH、negotiable=false、salaryMin>0、salaryMax>=salaryMin，两端都存在。月薪区间按上限比较，符合原型按max排序的语义。

年薪、日薪、面议、任一端缺失、零/负薪资及范围倒置，仍然返回并保持数据库原值，但排在有效月薪之后；尾部统一按更新时间和ID排序。这里没有按天数或薪资月数进行跨单位换算，也没有将尾部岗位解释为薪资较低。

排序先作用于全部过滤结果，再由PageHelper分页。SQL通过枚举选择固定分支，未使用`${sort}`拼接客户端输入。数据库DESC排序中NULL在有效月薪值之后，因此使用CASE产生薪资排序键。

前端接入时将“默认排序”映射到UPDATED_DESC，将“薪资排序”映射到SALARY_DESC，建议文案说明“按月薪上限，其他薪资置后”。请求参数不直接使用原型本地脚本的`salary`值。

## 影响与验收

- Controller 绑定枚举和分页参数，非法排序由参数异常处理返回明确错误。
- Service 校验求职者身份和分页，规范化关键词，固定可见状态，在finally清理PageHelper线程变量。
- Mapper 完成审核过滤、文本检索、固定排序与分页查询；数据库无迁移，列表VO无新增字段。
- 企业管理仍可查看本企业草稿、暂停、结束岗位；未审核企业仍可管理自己的岗位。企业主页继续执行自己的审核校验。

验收覆盖：审核/状态与搜索分组、两种数据来源、空技能、重复能力、月薪/年薪/日薪/面议/异常数值、排序稳定性、搜索排序分页组合、非法枚举、角色权限和业务数据不变。SQL绑定参数通过本地构造测试验证；含恶意字符串的HTTP样例未执行，见阶段报告中的Postman保存限制。持久回归位置及结果见阶段报告。
